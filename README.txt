VANGUARD 멀티플레이 실행 안내
============================

포함 파일
- vanguard_multiplayer.html : 솔로/멀티 게임 화면
- server.js                : 방 생성, 참가, 팀 선택 타이머, 실시간 플레이어 위치/피해 처리 서버
- package.json             : 서버 의존성

1) 준비
- Node.js 18 이상 설치
- 서버 코드는 Node.js 기본 모듈만 사용하므로 npm 패키지 설치가 필요하지 않습니다.

2) 서버 실행 (Windows)
- 이 폴더 안에서 주소 표시줄에 cmd 입력 후 Enter (또는 터미널 열기)
- 다음 명령 실행:
    node server.js
  (또는 npm start)
- 콘솔에 VANGUARD multiplayer server listening on ws://0.0.0.0:8080 가 보이면 서버가 실행 중입니다.
- 서버 창은 게임을 하는 동안 계속 열어 둡니다.

3) 게임 실행
- vanguard_multiplayer.html을 Chrome 또는 Edge로 엽니다.
- 게임 시작 > 멀티
- 닉네임 및 서버 주소를 입력합니다.
- 같은 컴퓨터에서 두 창으로 시험할 때 서버 주소는 ws://localhost:8080 입니다.
- 방 만들기를 누르면 5자리 방 코드가 나오고, 다른 창에서 같은 서버 주소와 코드를 입력해 방에 들어갑니다.
- 방장은 개인전 또는 팀전을 선택한 다음 게임 시작을 누릅니다.
- 개인전은 바로 시작하며 봇이 없습니다.
- 팀전은 20초 팀 선택 후 시작하고, 레드/블루 팀끼리는 피해를 주지 않습니다.
- 멀티에서는 AK-47을 포함한 모든 무기를 사용할 수 있습니다.

4) 다른 컴퓨터에서 접속
- 게임 HTML에 입력하는 서버 주소는 서버를 실행 중인 PC의 localhost가 아니라 해당 PC의 LAN IP 또는 공인 도메인이어야 합니다.
- 같은 Wi-Fi/LAN에서는 예를 들어 ws://192.168.1.20:8080 형식으로 입력합니다. Windows 방화벽에서 Node.js/8080 포트 통신을 허용해야 할 수 있습니다.
- 인터넷을 통해 다른 네트워크에서 접속하려면 서버를 공인 호스팅에 배포하거나 라우터 포트포워딩을 설정해야 합니다. HTTPS 사이트에 서버를 붙일 경우에는 WSS(예: wss://...)를 지원하는 TLS 프록시/호스팅이 필요합니다.
- localhost 주소는 다른 컴퓨터에서는 작동하지 않습니다.

현재 프로토타입 안내
- 실시간 방/닉네임/위치 동기화, 무기 명중에 대한 서버 측 체력 판정, 개인전/팀전, 팀 피해 차단, 20초 팀 선택을 구현했습니다.
- 멀티플레이 테스트를 위해 WebSocket 서버 실행이 필요합니다. HTML 파일만 단독으로 열면 솔로 모드는 플레이 가능하지만, 온라인 방은 접속할 서버가 없으면 작동하지 않습니다.
